\title{Реферат программы <<Анализатор эффективности стратегий координации для групп роботизированных наземных транспортно-технологических машин (АЭСК-НТТМ)>>}

\begin{document}

\maketitle

АЭСК-НТТМ предназначена для комплексного анализа результатов вычислительных экспериментов, проведённых в симуляторе многозадачной координации групп роботизированных наземных транспортно-технологических средств (СМК-НТТС). Программа реализует математические методы оценки справедливости распределения нагрузки и эффективности различных стратегий координации на основе коэффициента Джини, применяемого к двум ключевым показателям: количеству выполненных задач и энергетическим затратам каждой машины.

Программа может использоваться в научно-исследовательской деятельности для верификации и сравнения алгоритмов распределённого управления автономными системами, а также в учебном процессе при подготовке специалистов в области робототехники, интеллектуальных транспортных систем и автоматизированного управления. Она поддерживает обработку входных данных в формате JSON, генерирует сводные и детализированные отчёты в формате CSV, содержащие статистики по средним и медианным значениям коэффициентов Джини, а также метрики выполнения задач и энергоэффективности.

Функциональные возможности АЭСК-НТТМ включают:
\begin{itemize}
\item парсинг структурированных отчётов симулятора;
\item вычисление векторов распределения нагрузки по шагам моделирования;
\item расчёт коэффициентов Джини по задачам и энергозатратам;
\item агрегацию результатов по стратегиям и сценариям;
\item экспорт данных в CSV для последующего визуального и статистического анализа.
\end{itemize}

Программа реализована на языке Go, имеет модульную архитектуру и поддерживает параметризацию через командную строку. Объём исходного кода составляет 2,97 мегабайта (3 044,28 КБ, 3 117 340 байт).
