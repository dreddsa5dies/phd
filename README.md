# Моделирование и алгоритмы децентрализованной многозадачной координации комплекса роботизированных наземных транспортно-технологических машин

Диссертация на соискание ученой степени кандидата технических наук по специальности 2.5.11 - «Наземные транспортно-технологические средства и комплексы».

## Аннотация

Работа посвящена повышению эффективности комплексов роботизированных наземных транспортно-технологических машин (РНТТМ) при выполнении разнородных рабочих процессов за счет разработки имитационной модели и алгоритмов многозадачной координации на основе децентрализованного выбора задач.

В отличие от современных многоагентных систем, в которых доминируют методы глубокого обучения с подкреплением и централизованно-децентрализованные архитектуры, в работе предложен аналитический подход на основе теории игр, обеспечивающий:

- детерминированность и предсказуемость поведения РНТТМ без необходимости предварительного обучения;
- явный учет неоднородности навесного оборудования (ковши, отвалы, вибровальцы и т.п.);
- минимальный объем обмена служебной информацией (только скалярные значения приоритетов);
- вычислительную эффективность.
