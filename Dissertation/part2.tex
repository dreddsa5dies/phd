\chapter{Моделирование многозадачной координации в группе роботизированных НТТС}\label{ch:ch2}

Распределение задач между членами группы исполнителей -- классическая проблема с богатой историей и множеством применений. Традиционно распределение задач состоит в назначении каждому исполнителю одной из многих возможных задач таким образом, чтобы была оптимизирована метрика производительности и эффективности. Однако, в зависимости от структуры целевой функции, эта проблема может быть трудоемкой с точки зрения вычислений, т.\ к. требуется \textit{единый} центр принятия решений. Такая реализация требует устойчивой связи между НТТС, что может быть сложно реализовать в крупномасштабных системах из-за помех. Альтернативой этому подходу является предоставление НТТС возможности определять задачи и позволять им самостоятельно принимать решения о том, какую работу выполнять на основе общей стратегии в рамках своих ресурсов.

При этом возникает такой конфликт, что несколько НТТС в группе могут претендовать на выполнение одной и той же задачи одновременно. Это не будет являться эффективной стратегией. Для разрешения таких столкновений интересов и определения рациональной общей стратегии принятия решения предлагается воспользоваться математическими методами Теории игр \cite{GlobalGames, GlobalGames2, GlobalGamesRus, GlobalGamesRus2}. При таком подходе состояние системы будет частично контролироваться НТТС, которые имеют минимальное взаимодействие между собой и чьи действия будут влиять на других членов группы в пределах их зоны контроля. Преимущество заключается в том, что при простых предположениях о структуре функции вознаграждения НТТС в системе будут присутствовать байесовские равновесия Нэша (БРН).

\nomenclature{БРН}{байесовские равновесия Нэша\nomrefpage}

Графический замысел системы изображен на рис.\ \cref{fig:system_model}. По нему, конечное число НТТС должно выбирать из группового массива задачи. Каждый НТТС может иметь разное навесное оборудование для выполнения своего типа задач, а~также своей ограниченный ресурс. Очередь пополняется задачами из внешнего источника и от НТТС по распределению Пуассона. Каждая такая задача характеризуется независимыми случайными величинами, соответствующими их уровню сложности (сколько ресурсов будет затрачено на ее выполнение) и типом требуемого оборудования для ее выполнения. Задачи распределяются равномерно между всеми НТТС в группе. Координация между НТТС, необходимая для выполнения общей задачи, происходит посредством локальных взаимодействий по сети. Наконец, НТТС решает, какую из задач выполнить, и связанный с этим выигрыш зависит от выбранной задачи и от количества НТТС, принявших такое же решение.

\section{Описание модели системы}\label{sec:ch2/sec2}

Рассмотрим систему с $N>1$ НТТС входящими в множество $i \in \{ 1; \dotsc; N \} = [N]$. НТТС являются автономными роботизированными наземными транспортно-технологическими средствами, принимающими решения и выбирающими одну из задач групповой очереди, над которыми они должны работать. Обозначим через $R_i$ $i$-й НТТС. Каждый $R_i$ характеризуется набором характеристик $\langle \text{Eqp}_i, E_i \rangle$, включающим тип оборудования и объем доступного ресурса соответственно.

Поступление новых задач в систему осуществляется согласно двум \textbf{независимым} пуассоновским процессам так, что $\Pi_s(t)$ и $\Pi_l(t)$ независимы $\forall t$. Тогда суммарный поток $\Pi(t) = \Pi_s(t) + \Pi_l(t)$ является пуассоновским с интенсивностью $\lambda = \lambda_s + \lambda_l$.

Интенсивности $\lambda_s$ и $\lambda_l$ характеризуют среднее число задач, поступающих в единицу времени от соответствующих источников.

Процесс $\Pi(t)$, порождающий входящие задачи, является пуассоновским, если для любого временного интервала длины $T$ вероятность поступления ровно $k$ задач определяется законом Пуассона:
\begin{equation}
	\label{eq:queue_puasson}
	P_k(t) = \Pr\left(\Pi(t) = k\right) = \frac{(\lambda t)^k}{k!} e^{-\lambda t}, \quad k = 0, 1, 2, \dotsc
\end{equation}
где $ \lambda $ — интенсивность процесса.

Для двух независимых пуассоновских процессов суммарный входящий поток также является пуассоновским процессом с интенсивностью $\lambda = \lambda_s + \lambda_l$. Таким образом, групповую очередь задач, формируемую как внешним источником, так и НТТС, следует рассматривать, как единый поток задач для всей группы НТТС.

Каждой $j$-й задаче $T_j$ соответствует набор характеристик $\langle \Theta_{T_j}, \text{Req}_j \rangle$ включающий сложность выполнения (количество затрачиваемых ресурсов) задачи и~необходимый тип оборудования для ее выполнения.

$\Theta_T$ выбирается из гауссова распределения:
\begin{equation}
	\label{eq:theta_gauss}
	\Theta_T \sim \mathcal{N}_{[0, +\infty)}(\mu_T, \sigma_T^2), \quad \mu_T > 0, \sigma_T > 0,
\end{equation}

где $\Theta_T$ не может быть отрицательным.

У каждого $R_i$ есть ограниченный запас энергии $E_i \in [0, E_{\text{max}}]$, где $E_{\text{max}}$ -- максимальный запас энергии. Выполнение задачи $T$ требует затрат $e_T > 0$.

Динамика изменения энергии для $R_i$ описывается следующим образом:
\begin{equation}
	\label{eq:energy_ntts}
	E_i(t+\Delta t) = \min\left\{ \max\left\{ E_i(t) - e_{T_j} \cdot \mathbf{1}(A_i = T_j) + r_i \Delta t,  0 \right\}, E_{\text{max}} \right\},
\end{equation}

где $r_i > 0$ -- скорость восстановления энергии [ед.\ ресурса/время], $\Delta t$ -- шаг дискретизации, a $\mathbf{1}(A_i = T_j)$ — индикаторная функция, принимающая значение $1$, если $R_i$ выбрал задачу $T_j$, и $0$ в противном случае.

Общий групповой массив задач в системе задается множеством:
\begin{equation}
	\label{eq:global_queue}
	\mathcal{T}(t) = \{ T_1, T_2, \dotsc, T_{M(t)} \},
\end{equation}

где $M(t)$ это текущее количество доступных задач в момент времени $t$.

Каждый $R_i$ способен автономно принимать решения и выбирать задачи из~$\mathcal{T}(t)$.

Выбор задачи каждым $R_i$ ограничен. Задача $T_j \in \mathcal{T}(t)$ может быть назначена $R_i$, только если одновременно выполняются условия совместимости оборудования $\text{Eqp}_i \succeq \text{Req}_{T_j}$ и достаточности ресурса $E_i \geq \Theta_{T_j}$, где отношение $\succeq$ означает, что оборудование $R_i$ удовлетворяет или превосходит требования задачи $T_j$, а $\Theta_{T_j}$~-- объем ресурса, необходимого для выполнения задачи $T_j$, т.\ е.:
\begin{equation}
	\label{eq:choice_task}
	\mathcal{T}_i(t) = \left\{ T_j \in \mathcal{T}(t) \mid \text{Eqp}_i \succeq \text{Req}_{T_j},  E_i \geq \Theta_{T_j} \right\}.
\end{equation}

Тогда имеется вектор доступности задач для $R_i$ такой, что $B^{(i)} = (b_1^{(i)}, \dots, b_{M(t)}^{(i)})^\top$, где:
\begin{equation}
	\label{eq:matrix_task}
	b_j^{(i)} = \begin{cases}
		1, & \text{если } \text{Eqp}_i \succeq \text{Req}_{T_j} \text{ и } E_i \geq \Theta_{T_j} \\
		0, & \text{иначе}.
	\end{cases}
\end{equation}

Таким образом, $B^{(i)}$ описывает, что для каждого $R_i$ есть локальный массив задач из общего группового массива задач. При этом, одна и та же задача может быть доступна для разных $R$.

Предположим, что $R_i$ взаимодействуют в соответствии с графом влияния $\mathcal{G} = ([N], \mathcal{E})$, где $\mathcal{E}$ множество ребер графа. А также, что граф связан, неориентирован и без петель. Пусть $\mathcal{R}_i$ обозначает множество соседей $R_i$, $i \in [N]$.

Рассмотрим простейший случай, когда имеются два $[R_i, R_j] \in [N]$ и $(i, j) \in \mathcal{E}$, а также две задачи $T$ такие, что $[T_1, T_2] \in B^{(i)}$ и $[T_1, T_2] \in B^{(j)}$.

Так, каждый $R$ принимает двоичное решение $A_i$ так, что $A_i = k \text{ соответствует выбору задачи } T_k, k \in \{1,2\}$, т.\ е. соответствует $R$, решающему выполнить $T_1$ или $T_2$, соответственно. $R_i$ использует измеримое правило $\gamma_i: \mathbb{R}^2 \rightarrow \{ 1,2 \}$ по своим наблюдениям, чтобы вычислить требуемое решение. Правило представляет собой отображение из пространства наблюдения сигнала о решении для выполнения $T_1$ или $T_2$. Пусть $\Upsilon^{(i)} = [ \Upsilon_1^{(i)}, \Upsilon_2^{(i)} ]^{\mathsf{T}}$, тогда действие $R_i$ вычисляется в соответствии с:
\begin{equation}
	\label{eq:action_ntts}
	A_i = \gamma_i\left( \Upsilon^{\left(i\right)} \right).
\end{equation}

Поскольку $R$ связаны, можно предположить, что они участвуют в \textbf{координационной игре}, определяемой матрицей взаимодействия (табл.~\cref{tab:binGameTable}). Идея, лежащая в основе матрицы взаимодействия, заключается в том, что задача с затратами $\Theta_T$ становится легче по мере увеличения количества $R$ в системе. Однако задача будет успешно выполнена только в том случае, если достаточная доля $R$ в~окружении $ \mathcal{R}_i$ будет сотрудничать в выполнении одной и той же задачи. То есть выигрыш каждого $R$ зависит от выбора $T$ и $\mathcal{R}_i$.

где $\alpha > 0$ -- выигрыш за координацию, $\beta > 0$ -- штраф за сложность.

Рассмотрим матрицу бинарной игры (табл.\ \cref{tab:binGameTable}). Если два НТТС выбирают одну и ту же задачу, их выигрыш увеличивается, так как они координируют свои усилия. Если они выбирают разные задачи, их выигрыш уменьшается.

\begin{subequations}
Пусть $\kappa_{ij} \equiv \frac{|\mathcal{R}_i \cap \mathcal{R}_j|}{|\mathcal{R}_i| + |\mathcal{R}_j|}$ является степенью кооперации и $\mathcal{S}_{ij}$ обозначает множество БРН с чистой стратегией детерминированной координационной игры, тогда:
	\label{eq:brn}
	\begin{align}
		\Theta_{T_1} - \Theta_{T_2} < -\alpha\kappa_{ij} &
		\implies \mathcal{S}_{ij} = \{(T_1,T_1)\}; \label{eq:brn_1} \\
		|\Theta_{T_1} - \Theta_{T_2}| \leq \alpha\kappa_{ij} &
		\implies \mathcal{S}_{ij}=\{(T_1,T_1),(T_2,T_2)\}; \label{eq:brn_2} \\
		\Theta_{T_1} - \Theta_{T_2} > \alpha\kappa_{ij} &
		\implies \mathcal{S}_{ij} = \{(T_2,T_2)\}; \label{eq:brn_3}
	\end{align}
\end{subequations}

Утверждение проверяется с использованием определения БРН \cite{GlobalGames3}. Т.\ о. в описанной игре существует несколько БРН, которые зависят от разности сложностей задач $T$ и структуры графа взаимодействия $\mathcal{G}$.

Следовательно, существует такой режим работы, в котором НТТС $i$ и $j$ могут выбрать одно из нескольких равновесий в зависимости от значений переменных $\Theta_1$ и $\Theta_2$. Например, если верно выражение \eqref{eq:brn_1}, то все НТТС выбирают задачу $T_1$. Если верно \eqref{eq:brn_2}, то возможны два равновесия, когда все выбирают задачу $T_1$ или $T_2$. А при \eqref{eq:brn_3} -- все выбирают задачу $T_2$ соответственно. Более того, набор равновесий зависит от структуры окрестностей графа.

В координационной игре $i$-й НТТС одновременно выполняет одно действие со всеми своими соседями $\mathcal{R}_i$ \cite{GlobalGames4}, следовательно, можно определить его локальную функцию полезности. Пусть $T \equiv [T_1T_2]^{\mathtt{T}}$. Полезность $R_i$ в игре с одним из его соседей $j$ тогда определяется как:
\begin{equation}
	\label{eq:local_usefulness_ntts}
	\mathcal{V}_i(\mathbf{A}, \Theta) \equiv
	\displaystyle\sum_{j \in \mathcal{R}_i} \alpha \cdot \mathbf{1}(A_i = A_j) - \beta \Theta^{(A_i)},
\end{equation}
где $\Theta^{(k)} = \Theta_{T_k} \text{ для } k \in \{1,2\}$ и $\mathbf{A} = (A_1,\dots,A_N)$ -- вектор действий всех НТТС.

НТТС в такой игре действуют не кооперативным образом, стремясь получить свой индивидуальный максимальный выигрыш в отношении своей стратегической политики \cite{GlobalGames3}. Другими словами, НТТС стремятся увеличить свою локальную полезность, выбирая стратегию $\gamma_i$, которая повышает ожидаемый выигрыш.

Пусть $\Gamma$ -- профиль стратегии координации, т.\ е. набор политик координации, используемых всеми НТТС в системе. Тогда
\begin{equation}
	\label{eq:strategy_ntts}
	\Gamma \equiv (\gamma_1, \dots, \gamma_N),
\end{equation}
где $\gamma_i: \mathbb{R}^2 \rightarrow \{1,2\}$ является измеримой функцией, $i \in [N]$. Аналогично, пусть $\Gamma_{-i}$ обозначает профиль стратегии координации, используемый всеми НТТС, кроме $i$.

Учитывая $\Gamma_{-i}$, целью $i$-го НТТС является решение следующей (стохастической) задачи оптимизации:
\begin{equation}
	\label{eq:optima_ntts}
	\mathcal{J}_i(\gamma_i, \Gamma_{-i}) \equiv \mathbf{E}_{\Theta, \mathbf{A}_{-i}}\left[\mathcal{V}_i(\mathbf{A}, \Theta)\right],
\end{equation}
где математическое ожидание берется по распределению $\Theta$ и действиям $\mathbf{A}_{-i}$.

Таким образом, стратегия для профиля $\gamma^*=(\gamma_i^*, \dots, \gamma_N^*)$ является БРН для многозадачной гауссовой глобальной игры, если:

\begin{equation}
	\label{eq:gauss_ntts}
	\mathcal{J}_i\left(\gamma_i^*,\gamma_{-i}^*\right) \geq \mathcal{J}_i\left(\gamma_i,\gamma_{-i}^*\right), \gamma_i \in \Gamma_i, \forall i \in [N],
\end{equation}
т.\ е. стратегия $\gamma^*=(\gamma_i^*, \dots, \gamma_N^*)$ является БРН, если ни одно НТТС не может увеличить свой ожидаемый выигрыш, отклоняясь от своей стратегии при фиксированных стратегиях других НТТС.

\section{Вариации стратегий выбора задач роботизированными НТТС}

С учетом свойств НТТС и задач, которые должны быть выполнены, а также сформулированной модели, предлагается формализовать некоторые обобщенные $\Gamma$ распределения задач для групповой системы с~$N \geq 3$ НТТС и $M \geq 3$ задачами такие, как $\Gamma_{min\text{Э}}$ (\textbf{энергосберегающая} стратегия) и $\Gamma_{min\text{ВЗ}}$ (\textbf{минимизации временный задержек}).

Пусть функция полезности $\Gamma_{min\text{Э}}$ будет иметь вид:
\begin{equation}
	\label{eq:usefulness_ntts_energy}
	\mathcal{V}_i^{\mathrm{min}\mathcal{\text{Э}}}(\mathbf{A}, \Theta, E_i) = \alpha \sum_{j \in \mathcal{R}_i} \mathbf{1}(A_i = A_j) - \beta \frac{\Theta_{A_i}}{E_i}
\end{equation}
где $E_i$ -- текущий запас энергии $R_i$, $\Theta_{A_i}$ -- сложность выбранной задачи. Второе слагаемое отражает \textbf{энергоемкость на единицу ресурса}.

Матрица игры для $\Gamma_{min\text{Э}}$ будет определена как:
\begin{equation}
	\label{eq:matrix_ntts_energy}
	V_i(\mathbf{A}) = \alpha \cdot |\{ j \in \mathcal{R}_i : A_j = A_i \}| - \beta \frac{\Theta_{A_i}}{E_i}
\end{equation}

Тогда $\text{БРН}_{min\text{Э}}$ достигается при:
\begin{equation}
	\label{eq:brn_ntts_energy}
	A_i^* = \mathrm{min}_{k \in \mathcal{T}_i(t)} \left( \frac{\Theta_k}{E_i} - \frac{\alpha}{\beta} \cdot \mathbb{E}[|\{ j \in \mathcal{R}_i : A_j = k \}|] \right)
\end{equation}

Равновесие существует при $\frac{\alpha}{\beta} > \max_{k,l} \left| \frac{\Theta_k}{E_i} - \frac{\Theta_l}{E_i} \right|$.

Для формализации $\Gamma_{min\text{ВЗ}}$ введем время ожидания задачи $W_j$ с динамикой:
\begin{equation}
	\label{eq:time_ntts_time}
	W_j^{(t+1)} = \begin{cases}
		0 & \text{при выполнении} \\
		W_j^{(t)} \cdot e^{\lambda \Delta t} & \text{иначе}
	\end{cases}, \quad \lambda > 0
\end{equation}

$W_j(t)$ сходится при $t \to \infty$ если $\lambda < \frac{1}{|\mathcal{T}|} \sum_{k \in \mathcal{T}} \mu_k$, где $\mu_k$ -- интенсивность выполнения задачи \(T_k\).

Функция полезности $R_i$ для $\Gamma_{min\text{ВЗ}}$ будет представлена как:
\begin{equation}
	\label{eq:usefulness_ntts_time}
	\mathcal{V}_i^{\mathrm{min}\text{ВЗ}}(\mathbf{A}, \Theta) = -\beta W_{A_i}(t) \cdot \Theta_{A_i} + \alpha \sum_{j \in \mathcal{R}_i} \mathbf{1}(A_i = A_j),
\end{equation}

Тогда матрица игры стратегии описывается как:
\begin{equation}
	\label{eq:matrix_ntts_time}
	V_i(\mathbf{A}) = -\beta W_{A_i}(t) \Theta_{A_i} + \alpha \cdot |\{ j \in \mathcal{R}_i : A_j = A_i \}|
\end{equation}

И существует $\text{БРН}_{min\text{ВЗ}}$:
\begin{equation}

\end{equation}

\section*{Выводы по главе}\label{sec:ch2/sec5}

В главе рассмотрен вопрос перехода группы роботизированных НТТС от режима индивидуальной конкуренции к групповой кооперации с применением общих формализованных стратегий поведения на основе теории игр. Представлена формализованная математическая модель, которая учитывает динамику энергии, стохастичность задач и временные параметры. Сформулированы две стратегии поведения. Так, для энергосберегающей стратегии ($\Gamma_{\text{min}\text{Э}}$) учтены явная зависимость от $E_i$ в функции полезности и динамики энергии через $E_{\text{max}}$, введено понятие энергоемкости $\Theta_{A_i}/E_i$ как основной метрики. Для стратегии минимизации временных задержек ($\Gamma_{\text{min}\text{ВЗ}}$) введено время ожидания $W_j(t)$ с экспоненциальной динамикой, учтена явная связь времени выполнения и сложности задачи.

Одновременно с этим, при применении энергосберегающей стратегии в группе робототехнических НТТС предполагается, что экономный режим реализуется через механизм, напоминающий <<стадный интеллект>>: каждый НТТС минимизирует собственные затраты, но групповое поведение должно привести к глобальному оптимуму. При стратегии минимизации задержек НТТС постоянно перераспределяются между стареющими задачами, предотвращая временной рост задержек.

Дальнейшее направление исследования предполагает разработку алгоритмического обеспечения, программного комплекса и проведение вычислительных экспериментов для верификации и анализа эффективности предложенных стратегий в условиях моделируемой среды.
